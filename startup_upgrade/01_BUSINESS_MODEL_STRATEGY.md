## 1. 개요 및 패러다임 전환 (Paradigm Shift)

### 1.1 기존 모델(RunPod GPU 재판매)의 한계와 폐기 근거
과거 기획되었던 **RunPod 기반 GPU 중개/대여 모델**은 재무 및 운영 관점에서 다음과 같은 한계가 존재했습니다:

1. **변동 원가(COGS) 부담**:
   - 학생 1인당 월 20시간 Secure Cloud GPU(A5000)를 제공할 경우 원가율이 42.7%~50% 수준으로 높음.
   - 인스턴스를 켜두고 미사용 시 발생하는 유휴 자원 비용이 플랫폼 부담으로 작용.
2. **인프라 장애 및 운영 리스크**:
   - 클라우드 공급사의 리전 장애, 네트워크 지연, 인스턴스 할당 지연 시 플랫폼이 직접적인 CS 및 클레임 부담을 짐.
3. **결제 및 세무 처리**:
   - 해외 달러 결제(USD)에 따른 환율 변동성 및 국내 대학/기관과의 세금계산서 정산 절차 복잡성.

### 1.2 제로 인프라(BYOC/BYOG) 자산경량형 SaaS로의 전환
plAI-ground는 **"자체 GPU 서버를 대여하지 않고, 클라이언트 로컬 연산 및 무료 Google Colab을 활용하며 시각화와 무결성 평가 데이터만을 제공한다"**는 방향으로 전환합니다.

```
[ 기존 모델: GPU 리셀러 ]
사용자/대학 ──(결제)──> [ plAI-ground ] ──(외화 지출)──> [ RunPod GPU ]
                           │
                           └── 원가율 50%, 마진 제한, 인프라 장애 부담

[ 전환 모델: 무결성 검증 & 학습 시각화 순수 SaaS ]
사용자/대학 ──(결제)──> [ plAI-ground SaaS (ViewAI + DiffStack) ]
                           │ (연산 비용 지출 0원)
                           ├── 로컬 PC (RTX 3060/4060, Apple Silicon, CPU)
                           └── 무료 구글 코랩 (Google 무료 T4 GPU 활용)
```

- **결과**: 서버 연산 비용 지출 0원, 인프라 장애 리스크 최소화, 매출총이익률 98% 이상 확보.

## 3. 요금제별 상세 전략 및 법적·회계적 근거

### 3.1 Tier 1: Free Tier (Product-Led Growth 엔진)
- **목표**: 개발자 커뮤니티 및 컴퓨터공학/AI 전공 학생 대상 초기 사용자 확보.
- **제공 기능**:
  - 멀티 환경 원클릭 세팅 도구 (CLI `plaiground init`, Colab 1줄 연동, 로컬 데몬 브릿지) 무료 제공.
  - 오픈소스 커뮤니티 AI 모델 템플릿(ResNet, YOLO, Diffusion 등) 코드 탐색 및 Fork.
  - **계정당 검증 포트폴리오 5회 무료 생성권** 제공.
  - *(※ 시각화 기능 완전 제외: 무료 티어에서는 ViewAI 웹 시각화 대시보드가 제공되지 않으며, 터미널/CLI 텍스트 로그만 확인 가능)*
- **전환 트리거**:
  - 웹 대시보드 시각화 탭 진입 시 또는 5회 무료 포트폴리오 크레딧 소진 시 "Pro 플랜 업그레이드 시 ViewAI 실시간 시각화(2D 지표 및 3D 텐서)와 무제한 포트폴리오 생성 지원" 안내 모달 노출.

### 3.2 Tier 2: B2C Pro 개인 구독 (월 9,900원 / 연 99,000원)
- **목표 고객**: AI 엔지니어링 취업 준비생, 대학원 연구원, 독학 개발자.
- **핵심 제공 기능**:
  1. **무제한 검증 포트폴리오 발행**: 고유 URL을 통한 웹 포트폴리오 링크 생성 및 공유.
  2. **ViewAI 실시간 시각화 대시보드 (2D 지표 & 3D Full-Mesh)**: 2D 학습 곡선(Loss, Accuracy, Learning Rate Curve) 실시간 모니터링 및 가중치 행렬(Weights)의 3차원 메시 뷰, 레이어별 텐서 흐름 검사.
  3. **DiffStack 무결성 인증 뱃지**: 로컬/코랩 환경에서 직접 코드를 작성하고 학습을 완주했음을 인증하는 검증 데이터 제공.
  4. **커뮤니티 Fork & Run 확장**: 커뮤니티에 공개된 모델 가중치 및 실험 설정을 원클릭으로 로컬에 복제 및 재실행.
- **단위 경제성 (Unit Economics)**:
  - 포트폴리오 1건 생성 시 LLM API 비용: 약 15원.
  - 시각화 로그 저장(Cloudflare R2 + Supabase DB): 약 5원.
  - 월 10건 포트폴리오 생성 기준 인당 인프라 원가: 약 200원.
  - 월 9,900원 결제 시 **매출총이익 9,700원 (마진율 98.0%)**.

### 3.3 Tier 3-A: B2B 대학 학과 학기 라이선스 (한 학기 4,200,000원)

- **정가 기준**: 학과 전공 실습 기준 정원 60명 × 인당 월 20,000원 × 1개 학기 4개월 = **4,800,000원**.
- **최종 공급가**: **4,200,000원 (VAT 별도)** (약 12.5% 학과 특별 할인 적용).

#### 3.3.2 국가계약법 및 대학 행정 수의계약 근거
1. **『국가를 당사자로 하는 계약에 관한 법률 시행령』 제26조(수의계약에 의할 수 있는 경우)**:
   - 제1항 제5호 가목: **추정가격 2,000만 원 이하의 물품 제조·구매 또는 용역 계약은 수의계약 가능**.
2. **대학 예산 전결 규정**:
   - 대학 본부 입찰(경쟁입찰)을 거치지 않고 **학과장/단과대학장 전결(통상 500만 원 이하)** 한도 내에서 단일 견적서 기반 수의계약 체결 가능.
   - 계약 집행 기간을 1~2주 내로 단축하여 학기 시작 전 신속 도입 가능.

#### 3.3.3 학과 제공 핵심 기능
- **교수/조교 전용 LMS 대시보드**: 60명 학생의 주차별 실습 코드 진행률 및 학습 지표 모니터링.
- **코드 무결성 검증 (DiffStack)**: 학생의 코드 변경 이력 타임스탬프 분석을 통한 외부 복사/표절 확인.
- **실습실 PC 환경 통일**: 전산 실습실 PC 및 개인 노트북에 원클릭으로 동일 환경 배포.
- **단위 원가**: 60명 기준 한 학기 서버/DB/API 비용 약 35,000원 소요 → **매출 420만 원 대비 순이익 약 416.5만 원 (마진율 99.1%)**.

1. **KDT 훈련비용 지원 지침**:

- **수료 포트폴리오 일괄 발행**: 수료 시점에 30명 전원의 학습 이력 기반 검증 포트폴리오 생성.
- **단위 원가**: 30명 6개월 기준 서버/API 비용 약 28,000원 → **마진율 98.9%**.
