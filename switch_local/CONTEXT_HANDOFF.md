## 3. 확정된 세부 기술 아키텍처 및 평가 규격

### ⏱️ 과제 형식: 4시간 엔드투엔드 풀-라이프사이클
* 35~45분짜리 암기식 알고리즘 시험 배제.
* **4시간(240분) 엔지니어링 미션**:
  1. Phase 1 (0~45분): 데이터 파이프라인 버그 수정
  2. Phase 2 (45~150분): 초경량 모델 학습 & VRAM 4GB 제약 내 디버깅 최적화 (F1/Loss 수렴)
  3. Phase 3 (150~210분): 모델 가중치 체크포인트 저장 & 가벼운 추론(Inference) 서빙 스크립트 작성
  4. Phase 4 (210~240분): 회고 및 제출

### 🛡️ AI 어시스턴트 공급 및 보안 규격
* **무료 불안정 폴백(Omniroute 오픈소스 무료풀) 배제**: 지원자마다 AI 지능이 바뀌는 불공정 방지.
* **단일 모델 고정(Pinning)**: 최신 코딩 특화 모델인 **`GPT-6.1 Sol`** (또는 `Gemini 4 Argon`) 단일 제공.
* **1인당 1,000원($0.75) 크레딧 지갑**:
  * 웹 IDE 상단에 `[남은 크레딧: ₩1,000 | 40회]` 잔액 게이지 표시 (질문 1회당 약 15~20원 차감).
  * 1,000원 소진 시 자동 잠금 ➔ 대표님의 API 비용 상한선 절대 방어 (마진율 96% 이상 확정).

1. **모델 성능 & 자원 효율성 (40점)**: F1 수렴도, VRAM 4GB 준수, 상대 순위.
